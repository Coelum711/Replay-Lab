# Custom Object Interaction — 0.51

Replay Lab Custom Objects are content-agnostic story objects. A letter, phone, document, map, clue image, terminal, title card or any other story-specific visual remains the same engine type; templates only provide authoring defaults.

## Authoring model

Each object can contain multiple visual states and any number of hotspots. A hotspot is authored directly over the current state image by dragging and resizing a rectangle. It may be global or limited to a particular object state.

Hotspot actions currently include:

- no automatic action
- switch to another state
- hide/close the object
- show a transient note/hint

Interaction modes are:

- `none`: presentation only
- `inspect`: click to inspect/enlarge, click again to restore
- `stateful`: click to cycle through object states
- `pan-zoom`: drag to pan and use the wheel to zoom
- `hotspots`: hit-test authored hotspots and run their actions

## Script authority

Interactive changes persist while the script leaves the object alone. If a later Director row explicitly changes the same object's visibility, state, or transform, scripted state becomes authoritative again and the old interaction override is cleared.

This makes interactive and linear authoring safe to mix.

## Interaction Takes

Studio playtest can record an interaction session as a `CustomObjectInteractionTake`. A Take stores timestamped object-state and transform changes rather than video frames.

A Take can then be baked into normal Director rows such as:

```text
/wait 0.42
/object state "Diary" page_2
/wait 0.61
/object transform "Diary" 0.44 0.51 1.25 0
/object hide "Diary"
```

The numeric transform form is primarily a deterministic interchange/replay representation generated by the visual editor/recorder; ordinary authors are not expected to type those coordinates.

This gives one object two uses:

- playable VN/web build: the viewer interacts directly
- linear TRPG replay/MP4: the recorded Take is baked and replayed deterministically

## Current scope

0.51 intentionally uses rectangular hotspots. Polygon/lasso regions can be added later if actual projects demonstrate a need. Screen-space Custom Objects are interactive in this version; world-space story props remain presentation nodes until world interaction is explicitly added.

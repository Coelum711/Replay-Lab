Replay Lab 0.54.3-dev — 启动说明

本版完成整包检查与修复，详见 AUDIT_0.54.3_CN.md。
从 Studio 打开声音页可接续当前工程；旧版程序文件夹请保留备份。

克隆 + 文字情绪：先读 VOICE_BRIDGE_CN.md。
INSTALL_VOICE_BRIDGE.command 只安装独立依赖；START_VOICE_BRIDGE.command 启动本机桥。
实验路径需要 MLX 1.7B Base + 1.7B CustomVoice，不会自动下载模型。
已有 MLX 0.6B Base 继续用于普通 Voicebox 克隆，不需要删除或重下。
本包包含后端实现和离线测试；尚未通过 Apple Silicon 真机推理/试听验证。

不要直接双击 web/studio.html。
当前 Studio 使用 ES Module，浏览器在 file:// 模式下通常会拦截模块加载，结果就是“页面看得到，但很多按钮点不了”。

推荐：
- Windows: 双击 START_REPLAY_LAB.bat
- macOS: 双击 START_REPLAY_LAB.command（首次可能需要在系统设置中允许）
- Linux: 运行 ./START_REPLAY_LAB.sh
- 通用: python3 launch_replay_lab.py

启动器会在本机 127.0.0.1 启动一个静态 HTTP 服务器并自动打开 Studio。
关闭启动器窗口或按 Ctrl+C 即可停止。

如果你只是要做纯文字 Replay，不需要任何立绘；直接导入 Log/剧情台本即可，角色会使用占位立绘。

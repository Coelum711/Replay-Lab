# 0.54.2-dev：MLX 克隆情绪桥后端

## 本轮实现

- 独立本机桥：读取已有 Voicebox Profile 的参考音频，1.7B Base 提取并缓存声纹，1.7B CustomVoice 通过版本锁定的输入组装接入声纹和独立表演指令。
- 接入 `/health` + `/synthesize`；不向 stock `/generate` 发送自定义实验字段。桥身份、协议、Voicebox 地址、模型缓存和返回 Profile/注入确认均进行检查。
- 保留原有 0.6B 普通克隆路径；实验模式拒绝 0.6B 与跨尺寸声纹。不自动下载，不修改 Voicebox，不回退到预设声音。
- 角色表演配置与单句情绪覆盖分离，单句不复制/冻结角色 Profile；口音发音和韵律提示与台词分离，关闭口音时不发送。
- 返回实际 WAV 时长给工程编译器；限制并发、参考音频时长、请求大小、ZIP 展开体积和单次生成长度。
- 增加安装/启动器、状态页和中文下载/启动说明。

## 顺带修复

- 按“单句 → 角色 → 工程 → 台本”解析语言，auto 表示继承；角色声音 auto 槽可回退复用。
- 声音预览不重复应用舞台模板；模板只在明确操作时应用。
- 修复隐藏面板仍受 grid 样式显示的问题。
- 保存连接地址不改工程服务；创建翻译服务无写入副作用，改成显式设置 LibreTranslate 的按钮。
- 批量语音按每句实际语言/服务预检，不再只看角色表面的 auto 值。

## 没有完成或不包含

- Apple Silicon 真实推理、音色相似度、情绪/口音效果、速度和峰值内存验证。
- 真实 Voicebox 版本的全链路联调与本地浏览器视觉回归。
- Studio 与声音页自动接续未保存工程；仍需显式打开/连接工程目录。
- 多候选“采用这一版”工作流：目前点击生成成功后仍按原有流程写回音频，请先备份满意版本。

本包基于当前可取得的工程继续实现，不应把历史回复里未出现在源码中的 0.54.0 功能当作本包已具备。测试记录见 `TEST_RESULTS_0.54.2.md`。
